# Mycelium Monitor

All your apps in one place: up or down, costs, usage, API calls and admin access, plus a live map of every file and data store with a dot running along a line each time Claude Code or the app reads or writes it.

**Status:** v1 runs on Tristan's homelab and watches [Reroute](https://github.com/tristan-pofandt/reroute). Read [how it works](docs/architecture.md), the [roadmap](docs/roadmap.md) and the [design](DESIGN.md).

Part of the Mycelium family with [Mycelium Ops](https://github.com/tristan-pofandt/mycelium-ops) (running a company) and Mycelium Commerce (running a shop). All three share one look.
