# Mycelium Monitor: product

**What it is.** One place to watch several apps: up or down, uptime, costs, usage, API calls, admin access, and a live map of every file, data store, web address and outside API. A dot runs along a line each time Claude Code or the app reads or writes something. First app: Reroute.

**Who uses it.** Tristan today, a few times a day, often just a glance. He acts on access when something is wrong. Later: other developers and small teams running their own copy.

**The job.** In one look: is each app up, how did traffic and errors change since yesterday, what is it costing, and what is touching its data right now. One click opens the detail or the action.

**Mode.** A working dashboard. Easy scanning, the same controls everywhere, and a text version of every picture matter more than decoration.

**Look.** The shared Mycelium look (`DESIGN.md`). Monitor's signature is the live map: it has its own page and a card on the Overview.

**Limits.** Private site on the tailnet; public repo. Events are metadata only. Every visual has a keyboard and screen-reader version. Status is never colour alone. Reduced motion is honoured. Nothing is made up: numbers, insights and states come from real data.
